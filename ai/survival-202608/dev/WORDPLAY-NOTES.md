# P21 更新例子的讲解参考

- Spanish **llama**: 动物“大羊驼／美洲驼”，或“火焰”。课堂造句：
  La llama mira la llama.（大羊驼看着火焰。）
  对照邻居：Andes / wool / graze 与 fire / candle / heat。
  词义来源：https://dle.rae.es/llama
- French **glace**: “冰”或“镜子”。课堂造句：
  De la glace dans le verre, une glace devant moi.（杯里有冰，面前有一面镜子。）
  对照邻居：freeze / melt / snow 与 reflection / glass / face。
  词义来源：https://www.larousse.fr/dictionnaires/francais-anglais/glace/36976
- 中文 **东西**: dōngxi（物品，西轻声）与 dōngxī（东与西，西第一声）。
  可以说“东西带齐了，东西却分不清”，让学生先听读音，再观察物品词云
  与方位词云之间的光流。物品不对应一个固定英文单词，视语境可译 things、
  belongings 等；方位组合对应 east/west。这里展示的是文字层面的歧义与
  语境差异，实际口语还可以利用声调消歧。
