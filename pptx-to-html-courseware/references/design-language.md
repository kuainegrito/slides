# 设计语言与版式模式目录

> 目录：设计变量 / 配色体系 / 律动系统 / 版式模式目录（精修时直接选用）

## 1. 设计变量（deck.css :root）

```css
--paper: #fdfbf7;          /* 米白纸底 */
--ink: #2b2b33;            /* 主文字 */
--ink-soft: #6b6560;       /* 次要文字 */
--heart: #c2546a;          /* 心红（主强调） */
--heart-deep: #8e3a4d;     /* 深心红（渐变端） */
--vein: #3a5a78;           /* 静脉蓝（次强调） */
--line: rgba(43,43,51,.1); /* 分隔线 */
--sec-color: 由 sections.json 逐节注入
--ease: cubic-bezier(.2,.8,.2,1);
```

- 底纹：PPT 母版水彩图（bg-watercolor.webp）+ 白色渐变蒙层保可读性 + 底部 ECG 动画线
- 字体：标题 `"Noto Serif SC","Songti SC",serif`；正文 `"Noto Sans SC","PingFang SC",sans-serif`；大数字可 Georgia serif
- 参考站点风格：kuaiyu.site/teaching_innovation（编号小节、留白）、PhysioRushAI（律动）、notes/cycling-full-buff（节点缀色）

## 2. 配色体系（跨页视觉锚点）

**相位五色**（电活动/分期内容）：0期红 `#d9534f` / 1期橙 `#f0a04b` / 2期蓝 `#4d96ff` / 3期绿 `#6bcb77` / 4期紫 `#9b72cf`

**机械四相**（泵血周期）：充盈绿 / 等容收缩橙 / 射血红 / 等容舒张蓝（同源四色）

规则：**色彩只用于小面积强调**（左边条、曲线、徽章），水彩底保持可读；同一概念跨页同色。

## 3. 律动系统

- 入场：fade + rise + scale，缓动 `cubic-bezier(.2,.8,.2,1)`
- 步进时舞台 ECG 心跳脉冲（stageEl.classList 'beat'，重触发用 `void el.offsetWidth`）
- 标题下划线 sweep 动画
- 总开关 `html.motion-paused` + 尊重 `prefers-reduced-motion`

## 5. 精修版式纪律

1. 每页有清晰标题条，层级一致
2. 自动坐标还原 → 语义化版式（卡片/双栏/流程链），去除 PPT 残留空文本框与错位
3. 手绘示意图 SVG 配「教材原图小图」对照，兼顾美观与严谨
4. 1280×720 与 1920 宽屏下抽查不溢出
5. 内容勘误原则：**教材安静参考值与 app 演示值可并存**（注明出处），但曲线形态/分期边界必须与权威源一致
