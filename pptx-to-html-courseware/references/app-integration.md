# App 融合参考：互动点升级与权威数据反取

> 目录：互动点定位 / qrPoster 二维码封面 / 官方运行时数据反取 / 交互冲突处理 / 引导语写作

## 1. 互动点定位（实证优先）

- **第一证据**：PPT 里的二维码（qr_codes.json）与文本标注（"稳态软件""稳态模拟""微信小程序打开"）——教师在课堂上就是在这里把学生送往 app
- 设计性补充嵌入点（教学设计判断）标 `qr:false` 与实证点区分
- 一个 app 多个候选页时，选**教学高潮页**为主嵌入点（如压力感受性反射页之于 homeostasis 失血场景）

## 2. 二维码封面先行（qrPoster）

**课堂动线**：展示海报 → 学生扫码 → 教师按 → 大屏打开 app。

- 海报：官方双码（公网+校园网）16:9 图，约 1400×788 WebP，存 `assets/img/poster_<app>.webp`
- sections.json：`"qrPoster": "assets/img/poster_xxx.webp"`；封面加 `poster-mode` class
- CSS 目标：海报近乎铺满舞台（1280×720 下约 994×560，占 78%），标题压成细条
- **例外**：若 PPT 某页本身就是海报（整页二维码图），该页按普通幻灯片精修，不重复套封面
- 机制：封面与 iframe 同挂 `data-step=0`，按 → 封面淡出（`.on` → opacity 0 + visibility hidden）、iframe 淡入

## 3. 官方运行时数据反取（画图表的权威源）

**原则：宁可反取 app 的运行时数据，不对着截图手绘。**

1. 先找 app 的运行时资源：`https://kuaiyu.site/<app>/content/*.json`（如 `cycle.baseline.json`）、或前端 JS 里的模型定义
2. 抽取采样 → 转成本课件 `data/<x>_samples.js`（挂 `window.*`，2ms 抽点控制体积），deck.html 注册
3. 覆盖器数据驱动绘图：逐段着色、相位边界、关键点标注全部来自采样
4. 交叉验证：曲线控制点与 app 自述参数一致（如"数值优化标定教材值"）

**案例（心动周期 PV 环）**：`waveforms.lv.samples` + `waveforms.volume.samples`（800 点 1ms/点）→ 400 点；相位边界(ms) 100/150/270/450/510/650；EDV=120mL@10mmHg、ESV=50mL@95mmHg、Pmax=122@240ms。

**若必须手绘**：先定坐标映射量程，再检查**所有贝塞尔控制点**（不止端点）是否越界——控制点决定曲线方向，写错会"飞出图表"（教训：Y(80) 在量程上限 +40 的图里 = 冲出图外）。

## 4. 交互冲突处理

| 冲突 | 解法 |
|---|---|
| 左右边缘翻页热区盖住 app 边缘控件 | app 页加 `.app-mode` 隐藏 `.flip` 热区 |
| 翻页按钮遮挡 iframe | 用文档流独立 chrome 行（.pagenav），不用 fixed |
| 多 app 同时加载卡慢 | iframe 懒加载：进入才赋 src，离开置 `about:blank` |
| app 内滚动/按键被课件劫持 | 热键监听跳过 INPUT/TEXTAREA；iframe 内焦点天然隔离 |
| 深链直达 app 页 | 支持 `#app-<N>` 启动 hash 路由 |

## 5. 引导语写作（guide[]）

每个嵌入点写 3 步气泡：**先看什么 → 动手做什么 → 思考什么**。示例：

```
"页面滚到「五类细胞，同一传导序列」：认准心室肌细胞那条曲线"
"对比五种细胞：谁有 2 期平台？谁的 4 期不是平的？"
"勾选「为什么 T 波直立」——把电活动和心电图连起来"
```

- 第一步给**定位**（降低学生在 app 里迷路成本）
- 第二步给**操作**（制造具身经验）
- 第三步给**问题**（回扣本页知识点）
- app 页头同时保留 `note`（为什么在这里）与「新窗口打开 ↗」链接
