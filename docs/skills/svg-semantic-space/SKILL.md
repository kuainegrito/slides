# SVG 语义空间与高维投影

先明确观众需要感受到或理解的关系，再决定空间、镜头和文字的比重。教师口述页可把空间流动、聚合与关联作为主角，允许次要标签适度交叠；需要精读数值的页面则保留清晰标签与量纲。不要用整齐的卡片阵列替代用户要求的漂浮星云。

## 表示与视觉

- 原生 SVG 适合需要清晰缩放、可操作文字、渐变曲线及中等粒子量的场景。大量粒子先实测性能；超出预算时减少装饰、合并路径或评估 Canvas/WebGL，不把 SVG 当作所有规模的唯一答案。
- 分清源向量、降维或投影、三维场景、相机、二维屏幕五层。若无真实嵌入，使用可复现的合成向量，并在页面说明。词语标签不必等于一个 tokenizer token；上下文表示变化也不等于静态查表向量在移动。
- 保持投影算法有数学含义。可以将高维向量乘以三行正交基得到三维位置，再作视图旋转、平移和透视。装饰旋臂、尘埃与雾层单独标为场景几何；不声称它们是额外实测数据。
- 用 radialGradient、透明雾团、不同大小和深度的点、细旋臂以及曲线光流形成体积感。前景适当大、亮，后景小、淡；按深度安排词语绘制顺序。
- 优先复用 SVG 元素并更新属性，避免每帧重建场景。模糊滤镜只用于少量重点光带，避免对每个粒子做昂贵滤镜。按设备实测帧率和交互延迟，合理限帧。

## 镜头与语境叙事

- 同一词形的不同语义进入不同邻域；相关词和跨语言词放在相应语义区。双关例子要靠上下文区分，不暗示各语言总有一一对应的双关。
- 当前关联的两团词云提亮，其余淡化；可适度放大局部云团、文字与粒子。显示用放大保持独立于原始数据。光流端点、词语位置和镜头目标必须应用同一套显示变换。
- 跨区联系使用弯入纵深的曲线、逐步延展的光带、移动光粒及端点光晕。避免无解释的 h、坐标原点、箭头森林或占满空间的数值侧栏。
- 相机跟随同一三维曲线路径，而非仅在二维屏幕搬动标签。近远变化与平移要克制，防止端点跑出画面；手机需用两端的投影范围和文字边距共同适配取景。
- 一次播放包含起点阅读、平滑行进、到达口述三个阶段。具体时长按用户需求决定；本项目验证的例子是 3 秒 + 6 秒 + 5 秒。使用端点速度与加速度为零的 quintic smootherstep，避免急停。
- 停留时冻结镜头位置和朝向，背景尘埃可继续轻动。为口述保留暂停和手动切换；不必固定展示大块说明卡片。
- 开场总览属于页面实例状态。本项目首次进入显示 8 秒全景，再靠近 bank；循环不重复全景，离开并重新挂载才重播。允许直接选例子跳过开场。不要把这一选择写成全站持久开关。

## 实现与验收

- 将时间线、投影和数据分离；用真实经过时间驱动叙事，限帧只约束渲染。暂停后重置帧计时基准，避免后台时间导致跳帧跳例子。
- 离页卸载时取消 requestAnimationFrame、观察器和事件监听；遵守 reduced motion 与全局动效关闭。手动切换、自动播放、相机旋转、开场是否已播放应有独立状态。
- 用不依赖画面的检查验证投影、插值、时间边界、循环和端点连续性；用最终运行版本核对移动、停留、聚光、开场只播一次、重入复位、手机两端可见和控制不触发翻页。
- 本地视觉验收、公开 HTTP 哈希、实际线上浏览器验收分别记录，不相互替代。教师/学生版尽量共享交互模块，分别核对入口和数据缓存版本。
- 更新主源码和正常生成器；旧一次性补丁不能在重建时把最终效果覆盖回去。发布保留明确文件清单、基线校验和回滚备份，排除无关页面。

## 于快课件的特定约定

沿用原母版底色与原图；区分可编辑文字和烘焙在图中的文字。双语通常英文在前、中文在后，英文 Sans Serif Collection / #3f3f46，中文楷体 / #7030a0。字体子集包含新增汉字和外语重音，或确认后备字体确实覆盖。隐藏页按源文件与用户指定处理。
