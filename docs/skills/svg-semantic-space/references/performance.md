# 密集语义星云的性能与混合渲染

用于需要保留粒子、薄雾、文字和镜头纵深，同时解决低算力设备卡顿的场景。先测量瓶颈，再选择优化；少量元素的 SVG 场景不必提前引入光栅层。

## 渲染职责与共享坐标

- SVG 保留重点词、复杂连写或 RTL 文字、光流曲线、起终点光晕和可交互元素。数千个装饰粒子及雾层适合批量 Canvas 绘制；次要标签也可缓存为纹理，但需保留可访问的语义说明。
- Canvas 可放进 SVG 的 foreignObject，或用同尺寸叠层；两者必须共享世界坐标、局部放大、投影、相机、取景和显示尺寸，防止光流端点与云团漂移。根据需要安排层序，避免光栅层遮挡 SVG 交互。
- CSS 显示尺寸与 Canvas 内部分辨率分开。只在尺寸或像素比改变时重设画布大小，并应用对应坐标变换；每帧设置 width/height 会清空状态并重分配缓冲。像素比过高会放大填充成本，宜设设备相关上限。
- 用离屏纹理意味着该层是光栅。需要纯矢量导出时使用可控密度的 SVG 输出路径，不能把混合预览宣称为全矢量成品。

## 保留视觉，减少重复工作

- 粒子按语义区、颜色及少量透明度档位分桶，一次路径填充一组；剔除视野外粒子。很小的颗粒可用小矩形，较大颗粒再画圆，实际效果以最终尺寸检查。
- 雾层由少量 radialGradient 叠加，预绘成透明纹理，再按深度、局部放大和聚光权重贴图。雾在粒子下方，透明度克制，保持颗粒轮廓；不要逐帧重建渐变或给每粒施加模糊。
- 缓存次要文字的测量与纹理；保留各语言的字体、颜色和脚本方向。缓存键需覆盖会改变字形的条件，例如文字、字体、字号、语言和方向。字体加载完成或样式改变后失效重建；用适当倍率绘制纹理，检查镜头放大后的清晰度。
- 一帧只算一次相机三角函数、投影基与云团中心，供所有对象共用。复用缓冲和对象，减少密集循环中的临时数组与垃圾回收；词语深度顺序不变时不要反复操作 DOM 排序。
- 不活跃的光晕和光粒直接隐藏；文字描边只保留在确实需要的重点标签。分别观察移除滤镜、减少属性更新、缓存文字后的收益，避免把所有卡顿都归因于粒子数。

## 平滑时钟与自适应质量

- requestAnimationFrame 驱动渲染，按真实经过时间推进叙事。降低绘制频率或粒子数量不能改变开场、移动和到达停留的总时长。不要一边固定每帧推进进度，一边通过掉帧改变动画速度。
- 用多帧滚动窗口判定持续负载，而非单个慢帧。按稳定的粒子子集逐级降低密度，或适当降低光栅分辨率；优先保留重点词、光流和镜头。质量变化不重新随机生成整团星云，避免闪烁或跳形。
- 要恢复质量时使用更长稳定窗口和不同阈值，防止升降振荡。阈值取决于目标设备、场景与刷新率；本项目只做实例内逐级降密度，不把该策略当作所有可视化的固定规则。
- 用独立状态描述播放、轨道旋转和手动镜头，再按产品约定组合控制。本课件 Play 同时启用轮播和旋转，Pause 同时停住；到达停留时相机位置和朝向保持稳定。
- 暂停、后台隐藏和重入要有明确时钟语义。口述课件通常不应在恢复时补播后台积累的时间；恢复时重置计时基准。离页取消动画与监听，不在后台持续消耗资源。

## 如何验收“流畅”

在相同浏览器、视口、像素比、资源版本和可比播放阶段对照优化前后，记录冷启动与字体加载后的稳定段。至少经过一次开场、移动、到达停留和语境切换，并验证暂停恢复、手动操作与离页重入。

- 记录实际帧间隔、绘制函数耗时、样本量、DOM 节点数、绘制粒子数及质量档位。60 Hz 的帧预算约 16.7 ms；JS 绘制耗时不包括全部布局、合成及 GPU 工作，不能用它单独推算帧率。
- 平均值之外观察长帧，可记录帧间隔 p95/p99 或超预算帧比例；保证测量输出不会每帧频繁写 DOM。优化后若仍卡顿，区分计算、DOM/布局、滤镜与填充、文字、垃圾回收等成本，再决定是否进一步采用 WebGL。
- 窄屏和 CPU 降速模拟只说明对应测试条件；实体低端电脑或手机需要分别验证。没有实机证据时说明测试范围。
- 教师版、学生版共享渲染模块，仍需各自核对入口、缓存版本和控制行为。本地浏览器验收、线上文件哈希、线上浏览器验收分别记录。
