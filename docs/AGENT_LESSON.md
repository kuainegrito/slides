# Agent 教学过渡：从一个答案到一件完成的事

## 为什么调整

原内容 ID 36 的 Agent 页一直存在，但位于提示词与文化背景之后，主要讲搜索、收集、筛选与推送。当前任务把它前移、重制为生活类比，并保留原图入口。基础机制、语义与上下文、成文及成码先讲；接着介绍多工具复杂任务，再进入已有模拟器作品。P22/P25 仍是成文/成码页。

不要把主张讲成“所有人、所有任务都必须上 Agent”。建议口述：“先学会把一件事交代清楚。只有当任务需要多步推进、调用不同工具、根据结果调整时，Agent 的价值才更突出。”单步翻译、一次改写或简单问题可能只需普通对话。

概念依据：[Anthropic — Building effective agents](https://www.anthropic.com/research/building-effective-agents)。模型承担推理，Agent 系统组织工具使用与反馈循环；人工检查点仍有价值。本课件为预先编排的示意，不运行真实 Agent。动画中所有采购、冰箱与天气数据都为模拟。

## 问卷判读边界

- 沿用开场的 `session` / `survey` 参数和同一默认场次。默认显示全体，可筛选 student、teacher、both、other。每 5 秒只读更新，不发邮件、不提交答卷、不增后台字段。
- 本题分母是五个已知选项的实际回答数。chat、assisted、none 合计为“未自述使用 Agent”；unsure 单列，不能当作没有使用，也不能推断熟练程度。
- 少于 5 答：提示先口头询问；超过一半选择 chat/assisted/none：建议重点入门；否则 unsure 至少占三分之一：先澄清概念；否则 agent 超过一半：建议进阶讨论；其余为混合经验。阈值仅为讲解节奏启发，不是研究结论或显著性检验。
- 不自动跳过任何教学页。首次读取失败显示“无可用数据”；后续失败明确标注过时，保留上一结果。场次包含测试答卷时应先换正式场次再解读。

## 两版迁移任务

学生：用自己提供的笔记制作复习课件与练习网页，运行检查，核对来源并独立解释。教师：用审定资料制作课件、课堂练习与预览页，检查知识准确性、教学目标适配与实际活动效果。正式发送、发布、购买前保留人的确认。

## 实现与验证

`agent-lesson.js` 管理运行时插页、问卷回看与教学建议；`agent-scenes.js` 使用共享 SVG 光流实现场景；`agent-lesson.css` 适配独立画布与窄屏。新控件刻意不上传交互、输入或能力评分；`data-*` 和 `sceneRenderMs` 仅供本地状态与验收。沿用现有访问记录。

`scripts/test-agent-lesson.cjs` 覆盖两版顺序、原 ID 移动、问卷身份筛选、模拟分布建议、首次错误与过时状态、自动停在采购确认、库存足够分支、天气失败/重试、暂停与全局动效、原图、重播、重入、减少动态效果、390px 布局及开场备份。公网测试只读独立 `ai-survival-20261117-qa-agent` 场次，不种入合成答卷。人口分布与故障分支在本地请求夹具验证。
